1
Apple Developer Program 付费会员（¥688/年） — 有 Apple ID ≠ 有开发者资格。 没有付费会员，苹果不发放 Distribution 证书，世界上任何机器都签不出能装到你手机上的 ipa。 个人身份一般几小时到 2 天生效；这是唯一必须等时间的一步。
2
一台 macOS 编译器 — Windows 编译不了 iOS。用 GitHub Actions 的 macos-26 runner （带 Xcode 26，公开仓库免费）最省事；也可以租云 Mac 给我 SSH。两者选一个即可。
3
Apple 后台的双重认证 — 验证码只发你自己的设备，所以「登录后台点几下」必须你本人做。 我能做的是：把所有不需要登录的准备工作做完，把你要点的地方压缩到最少，然后接管出包、上传、生成安装链接的全部工作。
