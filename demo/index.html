怎么玩：切换渠道 → 点「重启 App」。命中投放渠道会走 开屏倒计时 → 视频试看 → 会员套餐 → 订单页 → 收银台 → 手机号登录； 自然量 / 关闭模块后只显示合规工具首页。倒计时可以按「跳过倒计时」快进。
后台改动即时生效：在 渠道展示后台 里勾掉栏目或模块， 回来点「重启 App」就能看到差异。所有配置都来自服务端 /demo/config，不是写死在页面里。
百度推广 API 归因：点「按 IP/设备号 自动归因」或打开后台给的验证链接， 服务端会用百度回传的点击 IP / 设备号匹配出渠道号（例如 bbdd1），再按该渠道自己的展示配置下发； 不再依赖剪贴板。
