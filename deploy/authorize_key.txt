在服务器 WebShell / 腾讯云「登录」终端里粘贴这一行（只需一次），即可授权本机免密部署：

mkdir -p ~/.ssh; chmod 700 ~/.ssh; if ! grep -q "workbuddy@kaiqi-local" ~/.ssh/authorized_keys 2>/dev/null; then echo "ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIAGuzbcna/+ju1+dnazgacAwGi0BmzmLYtq47v/Pl8+2 workbuddy@kaiqi-local" >> ~/.ssh/authorized_keys; fi; chmod 600 ~/.ssh/authorized_keys; echo AUTHORIZED

授权后本机执行：

python deploy/upload.py --check
python deploy/upload.py

若不想加公钥，也可以直接给 root 密码：

python deploy/upload.py --password '你的密码'
